# UX and reliability review (2026-11-26)

Whole-project review for ordinary users (home) and small offices: the web screens, install and
everyday running, and online research on similar products (Fing, Firewalla, eero, UniFi, Google
Home, Domotz, GlassWire, Circle, Norton Core, Pi-hole, AdGuard Home, Home Assistant). The biggest
claims were checked in the code. Owner rules still apply: no feature is removed (a simpler view
hides, it does not delete), no AI, no simulated data.

Summary: technically strong, but built for an IT administrator. An ordinary user meets three
problems: it stops without them noticing, it shows far more than they need, and nothing reaches
them when they are away.

## A. Fix first (bugs, safety)

1. **Nothing starts at boot or sign-in.** No `setLoginItemSettings` / `powerSaveBlocker` /
   `powerMonitor` in `apps/desktop/src`; the installer adds no Run entry; the `NigafiyEngine`
   service is never registered. After a restart or Windows Update monitoring stays off until the
   user opens the app. Fix: open at sign-in by default (hidden in the tray), keep the PC from
   sleeping while monitoring, restart the Sensor on resume; later, a tested service mode for offices.
2. **When the PC is off everything stops silently.** Database, API, web and Sensor all run on that
   PC; the DNS filter also stops resolving. Fix: an optional outside heartbeat (a push URL such as
   healthchecks.io / Uptime Kuma that alerts when pings stop), a "monitoring was off from X to Y"
   message when it comes back, and history that tells "device down" from "the monitor was off"
   (a top complaint about Domotz).
3. **Anyone on the Wi-Fi can create an account.** The installed copy listens on the LAN
   (`scripts/local.mjs:175`, `HTTPS_HOST=0.0.0.0`) and `ALLOW_REGISTRATION` defaults to true.
   A guest or an infected IoT device can register and try passwords. Fix: registration off on
   installed copies once the owner exists; hide "Create account" when it is off.
4. **Five Fleet pages have no sidebar link**: requests, scripts, jobs, patches, monitoring
   (`packages/shared-types/src/programs.ts:64` vs `apps/web/features/registry.tsx:252-271`);
   `/system/modules` likewise. Fix: add them to the program page lists.
5. **Errors show in English in the Arabic UI**, sometimes with field paths and raw JSON
   (`components/ui/feedback.tsx` ErrorNote, 216 uses; `lib/api.ts:30,46` fallbacks;
   `components/ui/data.tsx` Evidence). Fix: translate by error `code`; details behind a toggle.
6. **The owner of an installed copy has no password they know** (`owner-<random>@nigafiy.local`,
   random password in a DPAPI file, `apps/desktop/src/local-stack.cjs:161-165`). They cannot sign
   in from another browser, and a Windows reinstall loses access. Fix: "set your own password" on
   first run, with recovery codes.

## B. Biggest difference to the experience

7. **A "Home" view.** 7 programs, 37 features, 59 signed-in pages; Watch alone has 10 overlapping
   pages; the dashboard draws 19 widgets; a home user sees "Add a switch" and SSH prompts. A Home
   view shows ~6 widgets and hides IPAM, switch ports, port control, config backup, Mind and Fleet
   Pro (still reachable in the full view). Similar names to tidy: "Switch ports" vs "Switch port
   control", "Access control" vs "Access policies", "Live Monitoring" vs Fleet "Monitoring";
   repeated icons (ShieldCheck ×3, History ×2, GitBranch ×2, CalendarClock ×2).
8. **Control by person, not by device** (eero Profiles, Google Family Wi-Fi): each person's
   devices, one-tap pause per person, bedtimes with "+30 min" and "skip tonight", an **"Unknown
   devices" group** for new and randomized-MAC devices, and **checking that a pause really took
   effect** (top complaint about Google and Circle).
9. **"New device joined" alert** with Allow / Pause buttons (most valued feature in Firewalla,
   Fing, Domotz reviews).
10. **Telegram by QR instead of BotFather + chat ID**: scan, open the bot, Start, done; messages
    with action buttons. Telegram before WhatsApp: similar use in Egypt (72% vs 59%, Arab Finance
    2024), but WhatsApp needs the paid Business API and approved templates.
11. **Installable web app (PWA) with push**: no manifest or service worker today.
12. **Calm alerts by default**: three severities, quiet hours, mute per device / per type, a weekly
    summary instead of a stream (alert noise is why people leave Firewalla and GlassWire).

## C. Egypt

13. **Router connection assistant**: common ISP routers are ZTE ZXHN H188A (WE, Vodafone) and Huawei
    DG8045 (Vodafone), plus Zyxel. Detect the model, say where the sticker password is, and **warn
    before anything that could erase the PPPoE login** (a reset loses it and users rarely have it).
    Only the Zyxel VMG3625-T50B driver ran on real hardware; mark the other 15 "beta".

## D. Install and running

14. **Updates are off for everyone** (`NIGAFIY_UPDATE_MANIFEST_URL` unset in releases) and the user
    is not told. Build the manifest URL and public key into releases; tray notice on updates.
15. **Backup is command-line only** and needs separate PostgreSQL client tools; the doc's `.env`
    path is wrong (`%APPDATA%\Nigafiy\data`). Add "Back up now" + scheduled backups that include
    the encryption key (without it every stored router/SMTP secret is lost).
16. **164 MB unsigned installer** → SmartScreen / "Unknown publisher". Microsoft Store, or an
    illustrated explanation.
17. **A non-technical "start here" page**, English and Arabic: install, scan, get alerts on your
    phone. The READMEs start with Node, Go and pnpm.
18. **Access from outside home**: none today. Guided Tailscale or Cloudflare Tunnel setup.

## Also from the install review

- The Sensor gives up after 5 quick restarts and logs only to memory (~400 lines) in desktop mode;
  health is a tray tooltip only (`apps/desktop/src/collector-manager.cjs:236-251`).
- The Android app manages company phones (Device Owner); it is not a viewer. Label it so.
- Every page is a client component behind a boot spinner (`app/(app)/layout.tsx`).
- 11 tables scroll sideways on phones (portfolio 960–1040 px, hardware 900 px, switch view and
  patches 820 px). "→" in time ranges points the wrong way in Arabic.

## Not to do (lessons from other products)

- Never move a free feature behind a subscription (Fing, TP-Link HomeShield).
- Never let the product die when support or a subscription ends (Norton Core, Bitdefender BOX v1).
- Don't move menus around between releases (UniFi).
